# Welham Boys' School — The Architects of Human Potential

A scroll-driven cinematic tribute honoring the teachers of Welham Boys' School for Teachers' Day 2026.

## 🌐 Live Websites
- **Production Site:** [https://wbsteachersday2026.site/](https://wbsteachersday2026.site/)
- **GitHub Pages:** [https://jai-gagaliya.github.io/teachersday2026/](https://jai-gagaliya.github.io/teachersday2026/)

---

## ✨ Features
- **Cinematic Film Reel**: Smooth scroll-scrubbed multi-shot video transitions with deferred video buffering.
- **3D Interactive Background**: Three.js particle vortex and double golden torus rings reactive to scroll and cursor movement.
- **Hero 3D Perspective Tilt**: Depth perspective that follows pointer movement.
- **Interactive Lightbox**: Fullscreen accessible photo viewer with keyboard (`Esc`, arrow keys) and touch navigation.
- **Words of Inspiration**: Carousel of educator quotes with automatic rotation, progress indicators, and touch swipe.
- **Optimized Media Delivery**: Web-optimized video and image assets for instant loading on mobile and desktop.

## 🚀 Running Locally

### Option 1: Open Directly
Simply open `index.html` in any modern web browser.

### Option 2: Local Dev Server
```bash
npm install
npm run dev
```
Then visit `http://127.0.0.1:5173/`.
